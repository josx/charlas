## ¿Qué es una estrategia?
- Procedimiento para tomar decisiones
- Se utiliza para alcanzar uno o varios objetivos

## ¿Por qué Inteligencia Artificial **SOBERANA**?
- Gobernanza y auditoria
- Independencia Tecnológica
- Control de datos y privacidad
- Cumplimiento Normativo
- Disponibilidad asegurada y presupuestos predecibles

## ¿Cómo gestionar Grados de libertad sobre la IA?
- Mayor grado de control sobre stack Tecnológico
- Software libre + Modelos libres/Pesos abiertos

# Estrategia para una IA soberana

## Gobernanza - Gateway de IA
> 1er grado - Litellm/Bitfrost/Apisix

- Único punto de acceso de entrada y salida (Api keys internas)
- Interoperabilidad - Soporte para múltiples proveedores/modelos
- Trazabilidad de cada solicitud y respuesta
- Politicas de uso por persona o equipos
- Gestión de heuristicas para seleccion de modelos (rutas, fallback, load balancing)
- Control de Presupuestos
- Protección de datos y privaciad
    - Filtros/Guardrails especificos (PII, Denegaciones, Sesgos, etc)
    - Cumplimiento normativo de protección de datos (GDPR, ley 25326 etc)
    - Custom: Presidio (Anonimizar y enmascarar datos sensibles)

# Estrategia para una IA soberana
## Inferencia y Gestión de modelos
> 2do grado

- Hardware Propio (retail, enterprise) con Aceleradores: GPUs
- Nube + Alquiler GPUs (por tiempo) - Neoclouds
- Cuellos de botellas: VRAM, Ancho de banda, Cálculo
- Software: Vllm, Llama.cpp, Ollama, ComfyUI
### Modelos LLMs, System One, Disfusión
- Licencias pesos abiertos/libres (MIT, Apache2, etc)
- Algunos ejemplos: Qwen, Deepseek, Mistral, Kimi, Glm, Muse/Llama, Mimo, Gemma, clef, nimble
- Modelos: Densos, Moe, Quantizados (bf,fp,q), Billones de parámetros, MTP, MLX, GGUF
- Ventana de contexto, Kv-cache, prefill (entrada), generation (salida), t/s

# Estrategia para una IA soberana
## Aplicativo central y bases de conocimiento
> 3er grado
- Aplicación Interfaz Chat (Openwebui/Librechat/Onyx)
- Integración con Agentes, Skills, Tools, MCPs, APIs, etc
- Bases de conocimiento (automatizacion, sincronizacion, extracción, ingesta)
    - RAG: Generación Mejorada por Recuperación (embeedings, reranker, etc)
    - MCP conectores a DBs y APIs (mcp-toolbox)
    - OKF - Open Knowledge Format (DBs y Apis)
    - Control de calidad (Ragas)
- Observabilidad: Costos, Usos, Telemétria, monitoreo, evaluación y debug (languse/langwatch)
